Documentation

Everything you need to use, host, and understand Multi Obfuscator

How to use

  1. Select the language from the dropdown above (Lua, Luau, HTML, or Java)
  2. Paste your code in the left panel (or click the lightning icon to load an example)
  3. Adjust the obfuscation options — each language has its own set of techniques
  4. Click Obfuscate (or press Ctrl+Enter)
  5. Copy the result with the copy button or download it as a file

Supported formats

Lua 5.1 — Variable renaming with proper scope handling, encrypted string pool, global env wrapping, opaque predicates, anti-debug, anti-tamper, numbers as expressions, noise, nesting, and IIFE.

Luau — Everything from Lua + support for type annotations (type, export type), compound ops (+=, -=, ..=), continue, backtick string interpolation, and 0b binaries. Detected automatically.

HTML — Removes comments, encodes &lt;script&gt; content as bytes and runs it via eval + TextDecoder, encodes text as HTML entities, encodes attributes, minifies, and injects invisible noise elements.

Java — Removes comments, converts strings to new String(new char[]{...}), obfuscates numbers as expressions, encodes chars, and minifies without breaking tokens.

Serving locally

Since the file is a single .html, you can simply open it in your browser. To serve over HTTP:

# Python 3
python -m http.server 8000

# Node.js (npx)
npx serve .

# PHP
php -S localhost:8000

Then open http://localhost:8000/obfuscator.html in your browser.

Hosting in production

  • GitHub Pages — Create a repo, upload the .html, enable Pages in Settings → Pages
  • Netlify — Drag the file into app.netlify.com/drop
  • Vercel — vercel --prod or drag it into the dashboard
  • Cloudflare Pages — Upload directly from the panel
  • Any static hosting — Just drop the file on any web server

Security and privacy

All processing happens 100% in your browser. No code is ever sent to a server. You can use it offline by disconnecting from the internet. There are no analytics, cookies, trackers, or external calls.

Known limitations

HTML: Scripts using let/const at global scope may lose reference after encoding, because eval creates its own scope.

Java: Variable renaming is not available — it would require a full AST parser.

Lua/Luau: Control Flow Flattening and VM Obfuscation (used by Luraph/IronBrew) are not included — they require an embedded Lua interpreter.

Keyboard shortcuts

  • Ctrl + Enter or Cmd + Enter — Obfuscate
