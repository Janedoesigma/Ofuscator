Documentação

Tudo o que você precisa para usar, hospedar e entender o obfuscador

Como usar

  1. Selecione a linguagem no menu dropdown acima (Lua, Luau, HTML ou Java)
  2. Cole seu código no painel esquerdo (ou clique no raio ⚡ para carregar um exemplo)
  3. Ajuste as opções de ofuscação — cada linguagem tem seu conjunto de técnicas
  4. Clique em Ofuscar (ou pressione Ctrl+Enter)
  5. Copie o resultado com o botão de cópia ou baixe como arquivo

Formatos suportados

Lua 5.1 — Renomear variáveis com escopo correto, pool criptografado de strings, env wrapping de globais, predicados opacos, anti-debug, anti-tamper, números como expressões, ruído, aninhamento e IIFE.

Luau — Tudo do Lua + suporte a tipos (type, export type), compound ops (+=, -=, ..=), continue, string interpolation com backticks e binários 0b. Detectado automaticamente.

HTML — Remove comentários, codifica conteúdo de <script> em bytes e executa via eval + TextDecoder, codifica texto em entidades HTML, codifica atributos, minifica e injeta elementos invisíveis de ruído.

Java — Remove comentários, converte strings em new String(new char[]{...}), ofusca números como expressões, codifica chars e minifica sem quebrar tokens.

Como servir localmente

Como o arquivo é um único .html, você pode simplesmente abri-lo no navegador. Mas para servir via HTTP (necessário para algumas APIs como clipboard em alguns contextos):

# Python 3
python -m http.server 8000

# Node.js (npx)
npx serve .

# PHP
php -S localhost:8000

Depois acesse http://localhost:8000/obfuscator.html no navegador.

Como hospedar em produção

  • GitHub Pages — Crie um repositório, faça upload do .html, ative Pages em Settings → Pages
  • Netlify — Arraste o arquivo para app.netlify.com/drop
  • Vercel — vercel --prod ou arraste na dashboard
  • Cloudflare Pages — Upload direto pelo painel
  • Qualquer hosting estático — Basta colocar o arquivo em qualquer servidor web

Segurança e privacidade

Todo processamento acontece 100% no seu navegador. Nenhum código é enviado para servidor algum. Você pode usar offline desconectando a internet. Não há analytics, cookies, trackers ou chamadas externas.

Limitações importantes

HTML: Scripts que usam let/const no escopo global podem perder referência após a codificação, pois eval cria um escopo próprio.

Java: Renomeação de variáveis não está disponível — exigiria AST parser completo para preservar semântica.

Lua/Luau: Control Flow Flattening e VM Obfuscation (usados por Luraph/IronBrew) não estão inclusos — exigem interpretador Lua embutido.

Atalhos de teclado

  • Ctrl + Enter ou Cmd + Enter — Ofuscar código
  • Ctrl + C — Copiar saída (quando o botão de cópia está focado)
